The site cataloguing itself, which is recursive and unavoidable — a register of works has to include the register. The build ran deliberately out of the usual order: routes, schema and a document shell before any real content existed, on the theory that a layout designed against placeholder text produces the same section shape everywhere, because there's nothing particular to respond to.

The token system came first. Tailwind's default scales are wiped to `initial`, which makes `bg-slate-800` a build error rather than a convenient shortcut; two self-hosted faces and no third; no gradients and no box-shadow token in any of the four shadow namespaces, so a shadow is not discouraged but inexpressible. Six spacing values named by intent instead of by number.

The content layer checks itself rather than trusting the author. The record loader throws on a reused accession number or on a directory name that disagrees with its own frontmatter — either one means there are two answers to "which record is this." The article loader injects each note's parent accession before validation, so it arrives as a typed field instead of a path re-parsed in a template. Everything ships static: OG images render at build through Satori and resvg, RSS and sitemap are generated, and no route serves client JavaScript.

This record is the site cataloguing itself, which is a little recursive and unavoidable — a register of works has to include the register. The build followed its own phase map deliberately out of the usual order: routes, schema, and a document shell before any real content existed, on the theory that designing a layout against placeholder text just produces the same section shape everywhere, since there's nothing particular to respond to.

Phase 0 fixed the token system — a wiped Tailwind theme, two typefaces, no gradients, no box-shadows, a six-value spacing scale named by intent instead of by number. Phase 2a built the spine against a single fixture record: every route, the accession and note-uniqueness guards, a real Head component, zero client JavaScript. This record, and the seven others in the register, are Phase 2b — real dates and links, placeholder prose, so the layout gets built against actual field lengths instead of lorem ipsum.

What's left is the part that can't be scaffolded: the real writeups, in Langston's own words, for what each of these eight records actually is.

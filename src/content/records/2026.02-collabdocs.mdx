CollabDocs starts from the assumption that "real-time" is the whole feature, not a nice-to-have bolted onto a normal document editor. Every keystroke goes through Convex's reactive queries, which is what makes two cursors in the same paragraph feel like the same document instead of two documents politely diffing against each other.

The editor itself is TipTap, extended with the pieces a working doc tool actually needs: tables, task lists, an image extension, text alignment, a character count that doesn't lag behind typing. Auth runs through a password provider, which was the boring, correct choice over rolling anything custom.

The harder problem, still being worked through, is less about the editor and more about what happens when two people's changes land in the same sentence at once — that's where most of the remaining engineering effort actually is.
